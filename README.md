# George Videne · CV

CV-ul meu sub forma unui profil pe **Feedfolio**, o rețea socială inventată: povești evidențiate, postări-carusel, comentarii de la versiunile mele mai tinere și mesaje directe.

**Live:** https://videne.github.io/cv/

Alte variante:
- CV interactiv ca inbox: https://videne.memorabil.ro
- CV clasic PDF: [română](george-videne-cv.pdf) · [english](george-videne-cv-en.pdf)

## Structură

```
index.html              pagina (HTML, CSS și JS într-un singur fișier)
assets/                 imaginile folosite de pagină (avatar, portret duotone, wordmark, favicon, imagine de share)
brand/                  logo-uri și portrete în rezoluție mare, cu fundal transparent (PNG/SVG)
george-videne-cv*.pdf   CV-ul clasic, în română și engleză
```

## Publicare cu GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: **main** / **(root)** → Save.
După 1–2 minute, site-ul apare la `https://videne.github.io/cv/`.
